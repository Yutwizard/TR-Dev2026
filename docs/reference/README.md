# 📖 Reference Documents

This folder contains reference materials for the Treasury Management System.

---

## 📁 Related Data Files

The extracted reference data is located in `data/extracted/`:

| File | Description |
|------|-------------|
| `bank_code.txt` | BOT official bank code list (all Thai banks with codes) |
| `haircut_table.txt` | BOT standard haircut matrix for repo collateral |
| `stage_master.txt` | TFRS 9 ECL staging definitions |
| `table_master.txt` | Database table definitions |
| `all_tables_v4.txt` | Complete extracted table data from Excel |
| `docx_content.txt` | Extracted content from requirements DOCX |
| `pdf_content.txt` | Extracted content from requirements PDF |

## 📚 External References

### Regulatory
- [Bank of Thailand (BOT)](https://www.bot.or.th/) - Regulatory requirements
- [ThaiBMA](https://www.thaibma.or.th/) - Bond Market Association standards

- **TFRS 9 / IFRS 9** - Financial instrument accounting
- **Basel III** - Capital requirements
- **SWIFT** - Message standards (MT5xx series)

### Integration
- **BAHTNET** - BOT's real-time gross settlement system
- **TSD** - Thailand Securities Depository
- **SET** - Stock Exchange of Thailand
